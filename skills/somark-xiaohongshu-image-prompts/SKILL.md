# SoMark 小红书生图提示词

## 默认交付

只输出以下三部分：

1. **构图思路**：说明信息层级、视觉中心和阅读路径。
2. **生图提示词**：可直接复制使用的完整中文提示词。
3. **负面提示词**：列出必须避免的内容。

默认不要调用生图工具。只有用户明确说“直接生成图片”“帮我生图”或同等意思时，才使用 `imagegen`。

若用户只要求修改某一张图，进行精准微调：保留已经确认的标题、品牌色、比例与系列风格，只修改用户指出的问题。

## 工作流程

1. 提取用户给出的标题、正文、功能点、流程顺序、CTA、编号和参考图要求。
2. 判断页面类型：封面、痛点、原因、核心流程、工具分工、接入方式、案例、总结或互动 CTA。
3. 先写一句取舍说明。只有当横排过挤、信息过多或真实素材缺失时，说明简化方式和成本。
4. 将画面压缩到一个核心结论和最多三个主要视觉区域。
5. 从 [版式模式](references/layout-patterns.md) 选择最合适的构图，不机械套模板。
6. 输出构图思路、完整提示词和负面提示词。
7. 逐项核对文字、顺序、品牌规范、视觉均衡和事实边界。

信息缺失但不影响主方向时，用克制的合理默认值继续。只有关键命令、产品事实、官方 Logo、真实案例或会明显改变画面主线的内容缺失时，指出缺口并使用占位符，不虚构。

## 品牌硬约束

- 默认比例：`3:4` 竖版，`1080×1440`。
- 背景：哑光黑或深黑，辅以少量深灰。
- 核心橙色：严格使用 `#FF8C00`，作为唯一高饱和强调色。
- 辅助色：白色、浅灰、金属深灰。除非用户要求，不使用蓝紫渐变或彩虹色。
- 字体：全图中文、英文、数字统一使用 `思源黑体 / Source Han Sans SC / Noto Sans CJK SC`。标题用 Heavy/Bold，正文用 Regular/Medium。禁止艺术字、衬线体、斜体和字体变形。
- 字体生成并不可靠。在提示词中要求文字逐字准确；若文字、表格或 Logo 是发布级关键元素，建议后期排版或使用用户提供的真实素材。
- 品牌标识：没有官方 Logo 素材时，只使用清晰的 `SoMark` 文字，不虚构、变形或重新设计 Logo。联名页同理使用文字标识，如 `SoMark × 东软云科技`。

## 排版规则

- 主标题占画面上方约 30%–40%，控制在 1–3 行，手机缩略图下仍可读。
- 每页只保留一个视觉中心。SoMark 作为解决方案时可比其他节点放大约 20%–30%。
- 全图最多三个主要视觉区域；辅助标签不超过四项。
- 优先采用对称网格、等宽卡片、统一边距和明确对齐线。
- 横向四段流程在 3:4 画布中过挤时，改为斜向流程、上下分层或主节点加两侧输入输出。
- 不默认添加页码。只有用户明确提供页码或系列要求时才保留；不得擅自改编号。
- 标题、功能点、CTA 和流程顺序必须逐字保留。用户要求改文案时才调整。
- 保留足够留白，避免多套软件界面、机械装置、代码、粒子和卖点栏同时出现。
- 使用箭头表达交接，不用双向箭头制造职责混乱。

## SoMark 叙事主线

优先表达以下关系：

`PDF / 图片 / Office 文档 → SoMark 解析 → Markdown / JSON → RAG / Agent / 企业服务软件`

传达清晰分工：

- SoMark：提取、识别、整理文档结构。
- Agent：理解、总结、问答和执行任务。
- Skill / CLI：SoMark 的接入方式，不是与 Agent 并列的处理层。

常用结构问题包括：标题层级丢失、跨页内容截断、表格行列拆散、页眉页脚混入、分栏阅读顺序错误、图片文字漏读。

痛点页不要使用绝对结论“所有文档都无法被 AI 调用”。默认写成更准确的表达：

`企业文档格式多、元素复杂，直接交给 AI，结果往往不稳定。`

常见结果可收束为：

`找不到答案｜识别失败｜总结跑偏`

## 参考图修改

用户提供参考图时：

1. 先指出 1–3 个可验证的版式问题，如视觉重量失衡、模块过多、对齐混乱或信息重复。
2. 明确保留项和删除项。
3. 优先减少模块，不通过缩小文字塞入更多信息。
4. 若用户说“排列均衡”，使用等宽、等高、对称或上二下一的稳定结构。
5. 若用户说“简化”，删除装饰性流程、重复界面、大段代码和底部卖点栏，保留核心因果链。
6. 输出修改提示词，不直接生成或编辑图片，除非用户明确要求成图。

## 事实与素材边界

- 不虚构产品能力、安装命令、官方集成、客户案例、财务数据、工业参数或公司名称。
- Skill / CLI 命令未提供或未经验证时，保留明确占位符。
- 真实财报、研报、说明书和解析结果应使用用户上传的截图，并要求不重绘、不修改数字和正文。
- 产品效果使用“尽量保留”“降低影响”“结果更稳定”等克制措辞，不承诺绝对准确。
- 文档截图不得包含用户隐私、未公开机密或可识别的敏感数据。

## 提示词写法

完整提示词按以下顺序组织：

1. 画布、用途与整体风格。
2. 品牌配色和字体。
3. 标题及逐字文本。
4. 主体构图与各区域内容。
5. 箭头方向和信息流。
6. 视觉层级、留白和缩略图可读性。
7. 事实、Logo、截图和隐私约束。

负面提示词至少覆盖：复杂度、错误流程、字体、颜色、额外文字、乱码、错别字、假 Logo、虚构数据、人物或机器人、低清晰度。

- [ ] 只交付用户要求的内容，没有擅自生图。
- [ ] 比例为 3:4，橙色为 `#FF8C00`。
- [ ] 所有字体指定为思源黑体字族。
- [ ] 标题、功能点、CTA、编号和流程顺序准确。
- [ ] 一个视觉中心，最多三个主要区域，排列均衡。
- [ ] SoMark 是文档解析层，Agent 是理解和执行层。
- [ ] 没有虚构 Logo、命令、集成、案例或数据。
- [ ] 负面提示词覆盖复杂度、字体、颜色和文字错误。
